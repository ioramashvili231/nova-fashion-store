# NOVA — Fashion Store

## პროექტის შესახებ
NOVA არის ქართულენოვანი ონლაინ ტანსაცმლის მაღაზიის დემო ვებგვერდი. პროექტის მიზანია თანამედროვე, მარტივი და მომხმარებლისთვის მოსახერხებელი ონლაინ მაღაზიის შექმნა.

## გამოყენებული ტექნოლოგიები
- HTML5 — ვებგვერდის სტრუქტურა
- CSS3 — დიზაინი და რესპონსიული განლაგება
- JavaScript — ინტერაქტიული ფუნქციები

## ძირითადი ფუნქციები
- პროდუქციის დათვალიერება
- კატეგორიების არჩევა და ფილტრაცია
- პროდუქტების ძებნა და დახარისხება
- რჩეულებში დამატება
- კალათაში დამატება
- პროდუქტის დეტალების ნახვა
- მუქი რეჟიმი
- სიახლეების გამოწერის ფორმა

## პროექტის გაშვება
გახსენით `index.html` ნებისმიერ თანამედროვე ბრაუზერში.

## პროექტის ფაილები
- `index.html`
- `style.css`
- `script.js`

## შენიშვნა
პროექტი შექმნილია სასწავლო მიზნებისთვის. რეალური გადახდის სისტემა და მონაცემთა ბაზა არ არის ინტეგრირებული.
